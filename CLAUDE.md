# Estrategia de Ventas y Automatizaciones

Este proyecto contiene skills para vender servicios de diseño web y generar automatizaciones personalizadas para cada prospecto.

## Comportamiento al iniciar

Cuando el usuario escriba cualquier cosa, responde:

> **Listo para trabajar**
>
> ¿Qué hacemos?
> - **Analizar un prospecto** → dame la URL de su web o su @ de Instagram (o dime que no tiene nada)
> - **Crear una skill nueva** → describime qué proceso querés automatizar

Después activa la skill correspondiente automáticamente.

## Skills disponibles

- `estrategia-ventas-diseno-web` — Analiza un negocio y genera: diagnóstico, propuesta comercial, script de ventas y automatizaciones n8n listas para implementar
- `crear-skill` — Crea una nueva skill personalizada para cualquier proceso repetitivo
